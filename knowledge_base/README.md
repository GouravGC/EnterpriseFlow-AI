# EnterpriseFlow AI Knowledge Base

Place your source documents in this folder before running
the local bulk-ingestion script.

Supported formats:
- PDF
- TXT
- Markdown (.md)

Do not place API keys, passwords, personal records, or
confidential documents here unless you are authorized to
process them.

Documents in this folder are not indexed automatically.
Run `python ingest_knowledge_base.py` to index them.
